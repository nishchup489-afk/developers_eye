## Pick a reference by the question you have

- **How do I run it?** Read the [setup guide](https://github.com/nishchup489-afk/developers_eye/blob/main/setup-guide.md).
- **Why was this design chosen?** Browse the [decision, incident and experiment index](https://github.com/nishchup489-afk/developers_eye/blob/main/0_tech_docs/record-index.md).
- **How much did a change cost?** Read [Core trade-offs](https://github.com/nishchup489-afk/developers_eye/blob/main/CORE_TRADEOFFS.md), then follow the link to the measurement.
- **What happened during development?** Open the [engineering journal](https://github.com/nishchup489-afk/developers_eye/blob/main/0_tech_docs/journal/README.md) or the [technical handoff](https://github.com/nishchup489-afk/developers_eye/blob/main/technical_handoff.md). Dates matter when reading historical accounts.
- **How is this code licensed?** The repository includes its [MIT license](https://github.com/nishchup489-afk/developers_eye/blob/main/LICENSE).
