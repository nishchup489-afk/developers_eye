# Database schema and migrations

Area: backend · Status: active

## Purpose
Owns the PostgreSQL schema shared by the backend, crawler and indexer: the SQLAlchemy models in `backend/src/backend/models/` and the Alembic migration chain in `backend/alembic/`. The crawler and indexer import these models; they never define tables of their own.

## Rules for future changes
- Import every new model in `backend/src/backend/models/__init__.py` before running `alembic revision --autogenerate` (INC-0001).
- Read every autogenerated revision before committing; an `upgrade()` that is only `pass` is a bug (INC-0001).
- Never edit a revision that may already be applied; add a new forward revision (INC-0001).
